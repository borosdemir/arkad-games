Revive el clásico de 1993 con una versión moderna y rápida.
- **Sin complicaciones**: Juega directamente en tu navegador sin instalar nada.
- **Sin esperas**: Los archivos cargan rápido para que empieces a jugar de inmediato.
- **Diseño retro**: Una interfaz sencilla inspirada en el juego original.

Usamos un sistema de diseño moderno que le da una identidad única:
- **Colores Neón**: Morado y azul para un estilo gaming.
- **Estilo Moderno**: Interfaces con efectos de transparencia y profundidad.
- **Fácil de leer**: Pensado para que todo se encuentre rápido.

### ⚡ Rendimiento y Rapidez
- **Carga rápida**: Usamos Next.js 15 para que no pierdas tiempo esperando.
- **Para todos**: Se ve bien tanto en computadoras como en celulares.
- **Organizado**: Todo está estructurado para que Google lo encuentre fácilmente.

## 📦 Guía para Desarrolladores

### Requisitos
- Node.js instalado en tu equipo.

### Pasos para iniciar

1. **Descarga el código:**
   ```bash
   git clone https://github.com/borosdemir/arkad-games.git
   cd arkad-games
   ```

2. **Instala las librerías:**
   ```bash
   npm install
   ```

3. **Configura tu entorno:**
   Copia el archivo `.env.example` a `.env.local` y pon tus claves de Supabase.

4. **Inicia el proyecto:**
   ```bash
   npm run dev
   ```
   > Abre `http://localhost:3000` y ¡listo!
